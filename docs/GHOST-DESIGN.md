# 投影（Ghost）系统设计

> **本文是投影行为的设计 SSOT。**  
> 实现应对齐本文；数值真源仍是 `src/game/defaults.js`。  
> 代码：`feel/ghost-policy.js` · `feel/drag-session.js` · 绘制 `view.js`（不决定格坐标）。  
> 关联：[FEEL-DESIGN.md](./FEEL-DESIGN.md) · [PROJECT-HISTORY.md](./PROJECT-HISTORY.md)

**设计立场（2026-07-31 整理）**：  
近期问题（提前钉格、卡边太松、斜拖先横后斜、格缝连闪、横拖换格偏钝）大多来自**同一套阈值被多条补丁反复加减**，而不是缺一个新 if。  
本文把需求收成**可冲突消解的规则表**，实现应收敛到「一种核心模型 + 少量情境参数」，停止堆叠互相反制的补丁。

## 0. 术语（只保留这些）

| 名词 | 定义 |
|------|------|
| **本体** | 玩家拖着的块，视觉 origin = `frameX/Y`（含抬升） |
| **free** | 由本体映射到盘上的**浮点**想落点（格坐标，可在两格之间） |
| **sticky** | 当前展示的**整数**投影原点（画在盘上的那一格） |
| **lag** | `max(∣freeCol−sticky.col∣, ∣freeRow−sticky.row∣)` |
| **engage** | 是否允许显示投影（形状与棋盘是否「碰到」） |
| **open 方向** | 从 sticky 往该方向邻格 `fits` 为真 |
| **edge 方向** | 该方向邻格 `fits` 为假（贴边 / 贴占用） |
| **intent** | 本帧操作意图：`h` / `v` / `diag` / `idle`（由指移与 free 位移估计） |
| **落点投影** | 盘上半透明预览（ghost-policy 决策） |
| **Tray 扁影** | 摆放区脚下轮廓（纯绘制，不参与换格决策） |

**free 的几何定义（固定）**  
形状**最底一排**占格的水平中心 + 该排竖直中心 → 映射到棋盘格坐标 → 再减形状原点偏移，得到 `freeColF/freeRowF`。  
投影永远跟**本体视觉位置**，不跟「未抬升的手指」另算一套。

## 1. 玩家可感知目标（产品语言）

按优先级排序；冲突时**高优先级覆盖低优先级**。

| 优先级 | 目标 ID | 玩家感受 | 不可破坏 |
|--------|---------|----------|----------|
| P0 | **G-LEGAL** | 非法位置不画投影；松手只在合法格落子 | 是 |
| P0 | **G-BODY** | 投影跟着**块**走，不「影先到、块还在半路」 | 是 |
| P0 | **G-STABLE** | 停在格缝附近时投影**不连闪** | 是 |
| P1 | **G-TIMELY** | 开阔区明显拖过格中线后，投影**及时**切到邻格 | 是 |
| P1 | **G-EDGE** | 卡边/堵住时要**粘**，需明显多拖一段才换影 | 是 |
| P1 | **G-DIR** | 横拖主左右、竖拖主上下、斜拖优先对角，不「先横后斜」中间态 | 是 |
| P2 | **G-LAGCAP** | 影不能离块太远（甩影） | 是 |
| P2 | **G-LIFT** | 横移不因抬升公式导致投影整体上跳 | 是 |
| P3 | **G-FAST** | 快速扫过时仍跟得上（可略减粘滞） | 否（可牺牲边缘粘滞） |

## 2. 需求全表（从真机迭代沉淀）

### 2.1 功能需求

| ID | 需求 | 来源现象 | 设计回应 |
|----|------|----------|----------|
| R1 | 投影由本体位置驱动 | 影提前钉格 | free←本体；换格看 free 相对 sticky |
| R2 | 开阔区「到中线附近就切」 | 影钝、不跟手 | open 换格阈 ≈ **0.5 格**（半格中线） |
| R3 | 格缝停住不抖 | 两格间投影连闪 | **滞回 + 单一换格判决**，禁止多路径抢答 |
| R4 | 卡边需拖过约 **1.3 格** 才换 | 贴边一点就挤 | edge 方向阈 = **1.3**（与 open 分轨） |
| R5 | 斜拖不要先出纯横/纯竖中间影 | 左上拖先横后斜 | intent=diag 时只允许对角步进或钉住 |
| R6 | 横拖及时左右换格 | 防抖后横拖变钝 | open 横轴仍用半格；防抖不得用「全局 settle 锁死」误伤横移 |
| R7 | 影离块过远则灭影 | 影飞远处 | lag > MAX_LAG → 无投影（不钳盘边救命） |
| R8 | 抬升只计上移 | 横拖投影上跳 | drag-session 边界 |
| R9 | 仅合法投影 | — | !fits 不提交 sticky；commit 仅 valid |
| R10 | Tray 扁影与落点投影分离 | 绘制问题混谈 | 决策层不处理 tray 扁影 |

### 2.2 明确非目标

| 非目标 | 说明 |
|--------|------|
| 投影预测「下一意图格」 | 不做提前瞄准；只表达**当前 free 对应的合法钉格** |
| 与手指像素 1:1 的影 | 影是格点离散物；跟的是本体 free，不是触点 |
| 多套并行决策抢输出 | 禁止 freeSnap / stickyStep / diagForce 同帧各算一套再覆盖 |
| 用速度把 edge 压回 open | 卡边 1.3 是产品硬约束，不因快扫变成 0.5 |

## 3. 问题本质：不是缺补丁，是模型冲突

### 3.1 历史补丁如何互殴

| 补丁 | 为解决 | 副作用 |
|------|--------|--------|
| open 从 0.28→0.5 | 影提前 | — |
| hyst 从 0.06→0.14 | 格缝连闪 | **换格变钝**（实际阈 0.5+0.14） |
| sticky 换格后 70ms 冷却 | 连闪 | **横拖也延迟换格** |
| 斜向强制对角 + 失败 freeSnap | 先横后斜 | freeSnap 又在邻格间跳 → 再闪 |
| 步进失败就 freeSnap | 贴边卡住 | 格缝候选扫射 → 再闪 |

同一帧内若存在「步进失败 → free 邻域吸附 → 候选排序」多出口，**稳定与及时无法同时成立**。

### 3.2 必须在设计层消解的张力

```
        及时换格 (G-TIMELY)
              ▲
              │
   跟本体 ────┼──── 不抖 (G-STABLE)
              │
              ▼
        卡边粘 (G-EDGE)     斜向纯净 (G-DIR)
```

**消解原则（设计宪法）**：

1. **每个轴独立判决「是否离开 sticky」**（open/edge 分轨），不混成一个全局开关。  
2. **滞回只作用在「中线附近的离开/返回」**，不用「换格后时间锁」代替滞回。  
3. **同帧只允许一条成功换格路径**；失败则**保持 sticky**，禁止失败后改走另一套吸附。  
4. **intent 只过滤候选方向**，不单独再开一条会改 sticky 的强制路径（除非对角 fits）。  
5. **edge 阈值与 open 阈值不得共用一个被速度缩放的公式压到同一量级。**

## 4. 核心模型（实现应对齐的单一状态机）

### 4.1 每帧输入

```
originX/Y（本体）
  → freeColF, freeRowF
intent ∈ {h, v, diag, idle}   // 由指移 EMA + free 相对 sticky 估计
board.fits(matrix, r, c)
```

### 4.2 每帧输出

```
null                         // 未 engage 或 lag 过大或无合法钉格
| { originRow, originCol, valid: true, preclear }
```

### 4.3 状态

```
sticky: { row, col } | null
// 不需要 stickyAt 时间锁作为主防抖（见 §3.2）
// axisLock 可选：仅用于 intent=h/v 时限制次轴噪声
```

### 4.4 流水线（唯一合法顺序）

```
1. engage？否 → sticky=null，return null
2. 算 free、intent
3. sticky==null → 首次钉格（§5.1），return
4. sticky 非法（!fits）→ 清 sticky，走首次钉格
5. lag > MAX_LAG → sticky=null，return null
6. 对横、纵分别算 leave 阈值（§5.2 open/edge）
7. 用「中线 + 滞回」判定每轴是否请求离开 sticky（§5.3）
8. 按 intent 合成目标格（§5.4）—— 最多一个目标
9. 目标 fits 且 lag 合法 → sticky=目标；否则 sticky 不变
10. return sticky 的 hover（含 preclear）
```

**禁止**：步骤 9 失败后再跑「邻域 8 格搜索换一个更近的 sticky」（这是连闪主因之一）。  
**允许**：sticky 非法或 null 时的「首次钉格」使用有限邻域搜索。

## 5. 规则细则

### 5.1 首次钉格（sticky 为空或刚失效）

- `col0 = round(freeColF)`，`row0 = round(freeRowF)`（或 floor(free+0.5)）。  
- 若 `fits(row0,col0)` → 钉住。  
- 否则在 **±1 邻域**内找 lag 最小且 fits 的格；仍无则 **null**（不远吸）。  
- 首次钉格**不做** edge 1.3（尚无 sticky 可粘）。

### 5.2 离开阈值（分方向）

对 sticky 的四个方向分别：

| 方向邻格 | leave 阈值 L（格） |
|----------|-------------------|
| open（fits） | **L_open = 0.5** |
| edge（!fits） | **L_edge = 1.3** |

> 设计含义：开阔区「过中线」；卡边「过 1.3」。  
> **滞回不叠进 L**，滞回在 §5.3 单独建模。

### 5.3 滞回（只解决 G-STABLE，不牺牲整体手感）

相对 sticky 中心的一维 free 分量 `x`（列或行同理）：

```
当前 sticky 索引 = s

若 x >= s + L + H   → 请求向 + 离开（进入 s+1 一侧）
若 x <= s - L - H   → 请求向 − 离开
否则                → 该轴不离开
```

- **开阔**：`L = 0.5`，`H = H_open`（建议设计值 **0.08～0.10**）。  
  - 向 + 离开实际约在 **0.58～0.60**，返回需回到 **0.40～0.42** 以下 → 带宽防抖，横拖仍「过中线不久」就切。  
- **卡边**：`L = 1.3`，`H = H_edge`（建议 **0** 或 **≤0.05**）。  
  - 卡边硬阈值清晰；不必再叠大滞回。

**与错误补丁对比**：

| 做法 | 设计是否采纳 |
|------|----------------|
| 换格后强制 70ms 不能切 | **否**（横拖变钝） |
| 全局 hyst=0.14 且 open 再 +h | **否**（实际 0.64，体感钝） |
| 中线 ±H 的施密特触发 | **是** |

### 5.4 intent 合成目标（G-DIR）

设横轴请求 `dc ∈ {-1,0,+1}`，纵轴 `dr ∈ {-1,0,+1}`。

| intent | 目标合成 |
|--------|----------|
| **h** | `(s.row, s.col+dc)`；忽略 dr（次轴噪声） |
| **v** | `(s.row+dr, s.col)`；忽略 dc |
| **diag** | 若 `dc≠0 && dr≠0` → `(s.row+dr, s.col+dc)`；若仅一轴非 0 → **保持 sticky**（不产出纯轴中间态） |
| **idle** | 保持 sticky（除非 §5.3 已两边都离开且需处理——idle 时仍允许 open 双轴合成，见下） |

**idle / 慢挪**：允许 `(dr,dc)` 合成（含对角），因无「操作方向纯净」压力。  
**diag 仅一轴 leave**：保持 sticky，等到另一轴也 leave 或 intent 退回 h/v。

目标格 `!fits` → **保持 sticky**（不搜索替代格）。  
玩家继续拖 → free 变化 → 再次判决；或 lag>MAX_LAG → 灭影。

### 5.5 intent 估计（稳定、可测）

```
v = 0.35 * intentFinger + 0.65 * (free - sticky)   // 格单位
ax = |vx|, ay = |vy|
若 max(ax,ay) < ε_idle → idle
ratio = min(ax,ay) / max(ax,ay)
若 ratio ≥ DIAG_RATIO → diag
若 ax > ay + AXIS_BIAS → h
若 ay > ax + AXIS_BIAS → v
否则 → idle（或 both，按 idle 规则）
```

建议：`DIAG_RATIO ≈ 0.45`，`AXIS_BIAS ≈ 0.05`，`ε_idle ≈ 0.05`。  
intent 用 EMA 平滑指移，**禁止**对 sticky 再做一套与 free 无关的预测。

### 5.6 MAX_LAG

- `MAX_LAG > L_edge`（如 1.45 > 1.3），保证卡边拖满前影仍在。  
- 超过则 **灭影并清 sticky**，不吸附到远处合法格。

### 5.7 抬升（G-LIFT）

- free 只用本体视觉 origin。  
- 抬升 travel **仅手指上移**；横移不计入。  
- 投影模块不二次修正抬升。

### 5.8 快扫（G-FAST，可降级）

可选：指速高时仅将 **H_open** 略减（如 0.10→0.07），**禁止**降低 L_edge。  
不引入「快精整段改走 free 邻域搜索」。

## 6. 参数表（设计角色，非补丁旋钮）

| 参数 | 设计角色 | 建议出厂 | 禁止用法 |
|------|----------|----------|----------|
| `L_open` / OPEN_SNAP | 开阔离开中线 | **0.5** | 勿再降到 0.28「抢先」 |
| `H_open` / SNAP_HYST | 开阔施密特半宽 | **0.08～0.10** | 勿 >0.12 导致横拖钝 |
| `L_edge` / EDGE_HOLD | 卡边离开距离 | **1.3** | 勿被速度乘子压低 |
| `H_edge` | 卡边滞回 | **0～0.05** | 勿与 H_open 共用大值 |
| `MAX_LAG` | 甩影上限 | **1.45** | 必须 > L_edge |
| `DIAG_RATIO` | 斜向判定 | **0.45** | 勿与换格阈混用 |
| `AXIS_BIAS` | 横竖主轴 | **0.05** | — |

实现可将 `OPEN_SNAP`/`SNAP_HYST` 映射为 `L_open`/`H_open`，但**语义必须是施密特触发，不是「阈上再加 hyst 两次」**。

## 7. 验收用例（设计回归，替代「再打一补丁」）

| # | 操作 | 期望 |
|---|------|------|
| A1 | 开阔区沿水平慢拖，过格中线 | 过中线后约 0.08～0.10 内投影切邻列；**不**卡住半秒 |
| A2 | 停在两列正中微抖手指 | 投影**稳定**在一侧，不左右连闪 |
| A3 | 贴死边/贴占用往堵向拖 | 未满约 1.3 格投影不换到非法侧；不灭影（lag 允许） |
| A4 | 左上/右上斜拖 | 投影走对角或保持；**无**稳定的「先横移一格」中间态 |
| A5 | 纯横拖 | 投影主要变列，不因抬升整体上跳 |
| A6 | 快速甩离盘面 | 投影消失，不飞到远处合法角 |
| A7 | 非法区悬停 | 无投影或保持上一合法 sticky 直至 leave/灭影（与 G-LEGAL 一致：不画非法格） |

任一条失败：先改 **§5 规则或 §6 参数角色**，再改代码；禁止只加一条与 §4 流水线平行的特殊分支。

## 10. 演进约定

1. **改投影行为 = 先改本文 §1 / §2 / §5，再改代码。**  
2. 真机新现象：先归类到 G-* 目标冲突，再决定改优先级或改参数角色。  
3. **禁止恢复**：横移计入抬升、远距吸附救命、open≪0.5 抢先钉格、失败后邻域乱吸、用长时间 settle 代替滞回。  
4. Tray 扁影 / 半透明渲染问题走 view 工程项，不写入换格状态机。
