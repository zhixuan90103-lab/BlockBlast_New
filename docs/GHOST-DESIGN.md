## 一、从 Bug / 补丁 → 设计（重构叙事）

### 1.1 问题不是「缺补丁」，是「没有单一模型」

真机迭代里，投影问题被**逐个补丁**处理，同一套阈值被反复加减，互相打架：

| 阶段 | 现象（Bug） | 当时补丁 | 副作用 |
|------|-------------|---------|--------|
| A | 影提前钉格 | open 抬到 0.5 | — |
| B | 格缝左右连闪 | hyst 加大、换格时间锁 | 横拖变钝 |
| C | 斜拖先横后斜 | 强制对角 + 失败 freeSnap | 邻域乱吸 → 再闪 |
| D | 卡边太松 | edge=1.3 | 与滞回/灭影叠在一起难调 |
| E | 斜拖本体过了影不跟 | 再调 intent / settle | 与 B、C 冲突 |
| F | 贴边斜绕影死钉 | 允许斜向先单轴一格 | 接受中间态换跟手 |

**重构原则**：每个现象归入**产品目标**，用**一条流水线 + 少量有角色的参数**回答，禁止并行状态机。

### 1.2 Bug → 目标 → 设计规则

| Bug | 产品目标 | 设计规则（终态） |
|-----|----------|------------------|
| 影提前到格 | 跟本体 | free←本体；空地 **L=0.5** 过中线才 leave |
| 格缝连闪 | **不闪（P0）** | **H_open 施密特**；失败只钉住；禁止时间锁 |
| 横拖偏钝 | 及时 | 去掉 settle；H 有上限但不砍到会闪 |
| 卡边一点就挤 | 卡边粘 | **L_edge=1.3**，不被速度压低 |
| 先横后斜 / 影落后 | 方向 + 跟手 | **8 向**；斜向优先对角，**允许**先横/竖一格（方案 1） |
| 影飞远处 | 不甩影 | lag > **MAX_LAG** 灭影，不 nearest 全盘 |
| 横拖影上跳 | 抬升边界 | 抬升 travel **只计上移** |

### 1.3 方法栈（检索后采纳）

| 采用 | 类比 |
|------|------|
| 离散 sticky 格 | 编辑器 / RTS ghost |
| 施密特滞回 | 建造吸附防 snap jitter |
| 合法/非法分 L | 磁吸：易进难离 |
| 8 向一步 | 摇杆 8-way |
| 失败保持 / MAX_LAG | 反甩影 |

**不采用**：全盘 nearest、换格时间锁、失败 8 邻乱吸、无 H 纯 round。

### 1.4 方法一句话（实现必须对齐）

> **8 向步进 + 空地 0.5 / 盘内贴块 1.0 / 棋盘外沿 1.3 + 防抖不闪 + 斜向可单轴中间态 + 失败钉住 / 过远灭影**；投影跟**本体 free**。

## 二、术语

| 名词 | 定义 |
|------|------|
| **本体** | 拖着的块，视觉 origin（含抬升） |
| **free** | 本体 → 盘面浮点想落点（形状**最底一排**中心映射） |
| **sticky** | 当前投影整数 origin |
| **lag** | `max(∣Δcol∣, ∣Δrow∣)` |
| **8 邻** | 相对 sticky 一步的 8 个方向 |
| **不卡边** | 该轴一步后 origin **fits** |
| **卡边** | 该轴一步 **!fits** |
| **落点投影** | ghost-policy 决策结果 |
| **Tray 扁影** | 摆放区脚下影，**不参与**决策 |

## 四、统一流水线（唯一）

```
1. 未 engage → 清 sticky，无影
2. 算 free（本体）
3. sticky 空/非法 → firstPin（round ±1，仅此可搜索）
4. lag > MAX_LAG → 清 sticky，灭影
5. primary8Dir(free−sticky) → 主方向 (dc,dr) 或 null
6. null（中心死区）→ 保持 sticky
7. 纯横/竖：该向 leave 够 → tryCommit 一格；否则保持
8. 斜向：
     双轴 leave → 优先对角，失败再较强轴单步
     仅横 leave → 先横一格
     仅竖 leave → 先竖一格
     都不够 / 目标 !fits → 保持
9. 同帧禁止：失败后再跑邻域乱吸
```

## 五、规则细则

### 5.1 free

形状最底一排中心 → 盘格 → 减原点偏移。  
抬升只计**手指上移**（`drag-session`）。

### 5.2 primary8Dir

```
死区 → null
min/max ≥ DIAG_RATIO 且双轴非 0 → 对角
否则主轴（横或竖）；未达 ratio 不强制对角
```

### 5.3 离开阈值（分轴）

| 该轴一步结果 | L | H | 向 + 离开约 |
|--------------|---|---|-------------|
| **空地** fits | 0.5 | 0.12 | **0.62** |
| **盘内贴块**（界内叠块） | **1.0** | ≈0.04 | **1.04** |
| **棋盘外沿**（会出界） | **1.3** | ≈0.04 | **1.34** |

判定：`fits` → 空地；否则任一块出 8×8 → 外沿；否则 → 贴块。  
L 只是离开成本，**不会**把影落到非法格。

### 5.4 防闪

施密特 H；**禁止**换格后时间锁。

### 5.5 MAX_LAG

**1.45**（> 1.3）。过远灭影，不远距吸附。

### 5.6 firstPin

仅 sticky 空/非法：±1 合法邻 lag 最小。
