## 0. 方法栈（检索后采纳，非凭空）

正版 Block Blast 投影算法**无公开实现**可抄。开源 block puzzle 多数停在 `round + fits`。  
下列组件来自**可检索的通用实践**，再映射到本品类：

| 组件 | 业界常见用途 | 本项目用法 |
|------|----------------|------------|
| **离散 sticky 格** | RTS/编辑器 ghost、snap-to-grid | 投影钉在整数 origin |
| **施密特 / 滞回** | 建造吸附防 jitter（如 Valheim PlantEasily 写明 hysteresis 防 snap jitter）；UI 门限防抖 | **H_open**：空地离开/返回不对称，**优先不闪** |
| **分阈值粘性** | 磁吸目标：合法易进、非法难离 | **L_open=0.5** / **L_edge=1.3** |
| **8 向离散** | 摇杆 8-way（死区+扇区） | free 相对 sticky → 一步到 8 邻 |
| **失败保持** | 避免 nearest 乱吸 | 目标 !fits → 钉住；lag 过大 → 灭影 |
| **仅首次邻域搜索** | 放置失败时的有限恢复 | 仅 sticky 空/非法时 ±1 搜索 |

**明确不采用**

| 方案 | 原因 |
|------|------|
| 每帧全盘 nearest 合法格 | 甩影、飞远处 |
| 换格后固定时间锁 | 横拖变钝，非标准吸附解法 |
| 失败后 8 邻域乱吸 | 连闪主因之一 |
| 无滞回纯 round | 格缝必闪 |

**方法一句话**  
> **8 向步进 + 合法/非法分阈值离开 + 施密特防抖 + 失败钉住/过远灭影**；投影跟**本体 free**，不预测下一格。

## 1. 术语

| 名词 | 定义 |
|------|------|
| **本体** | 拖着的块，视觉 origin（含抬升） |
| **free** | 本体 → 盘面浮点想落点（形状**最底一排**中心映射） |
| **sticky** | 当前投影整数 origin |
| **lag** | `max(∣Δcol∣, ∣Δrow∣)`（free 与 sticky） |
| **8 邻** | 相对 sticky 的 `(dr,dc)∈{-1,0,1}² \ {(0,0)}` |
| **不卡边** | 沿该轴一步后的邻 origin **fits** |
| **卡边** | 该轴一步 **!fits**（贴块/出界） |
| **落点投影** | ghost-policy 决策的半透明预览 |
| **Tray 扁影** | 摆放区脚下影，**不参与**换格决策 |

## 2. 产品目标（优先级）

冲突时高优先级覆盖低优先级。**防闪（G-STABLE）与合法（G-LEGAL）为硬约束。**

| 优先级 | ID | 玩家感受 |
|--------|-----|----------|
| P0 | G-LEGAL | 非法不画影；松手只合法落子 |
| P0 | G-STABLE | **格缝绝不连闪**（可略粘） |
| P0 | G-BODY | 影跟块，不「影先到」 |
| P1 | G-TIMELY | 空地过中线后及时换格 |
| P1 | G-EDGE | 卡边约 **1.3 格** 才肯松 |
| P1 | G-DIR | 8 向语义清楚；斜向优先对角，**允许**先横/先竖一格中间态（跟手，拍板方案 1） |
| P2 | G-LAGCAP | 影离块过远则灭影 |
| P2 | G-LIFT | 横移不因抬升导致影整体上跳 |

**产品拍板（已定）**

1. 卡边继续 **1.3**（不用 1.5）  
2. 斜向：**优先**双轴都过阈 → 对角；**仅一轴过阈 → 允许先横或先竖一格**（中间态，跟手）  
3. 防抖：**不能闪**，H 取稳不取飘

## 3. 统一判决（唯一流水线）

```
每帧：
  1. 未 engage → sticky=null，无影
  2. 算 free（本体）
  3. sticky 空或非法 → firstPin（round + ±1 合法邻，仅此可搜索）
  4. lag > MAX_LAG → sticky=null，灭影
  5. dx,dy = free - sticky
  6. primary8Dir(dx,dy) → 主方向 (dc,dr) 或 null（中心死区）
  7. null → 保持 sticky
  8. canLeaveToward(dc,dr)？否 → 保持
       是 → 目标 = sticky+(dr,dc)
  9. 目标 out of range 或 !fits 或 lag 过大 → 保持
 10. 否则 commit sticky = 目标
```

**同帧单出口**：步骤 8–9 失败**只保持**，禁止再跑 freeSnap/邻域排序。

## 4. 规则细则

### 4.1 free（固定）

形状最底一排水平中心 + 该排竖直中心 → 盘格坐标 → 减形状原点偏移。  
抬升只影响本体视觉 origin → free 跟着变；**抬升 travel 只计手指上移**（drag-session）。

### 4.2 8 向主方向 `primary8Dir`

```
死区：|dx|,|dy| 都很小 → null（钉住）
若 |dx|,|dy| 均非 0 且 min/max ≥ DIAG_RATIO → 对角 (sc, sr)
否则若 |dx| 明显大 → 纯横 (sc, 0)
否则若 |dy| 明显大 → 纯竖 (0, sr)
否则（未达斜向比例）→ 只跟更强轴，不提前对角
```

| 方向 | (dc,dr) |
|------|---------|
| E/W/N/S | 单轴 ±1 |
| NE/NW/SE/SW | 双轴 ±1 |

**补漏**：未达 `DIAG_RATIO` 时**禁止**强行对角（否则「假斜向」要等双轴 0.5，本体已过影不跟）。

### 4.3 离开阈值 `canLeaveToward`（分轴）

对主方向涉及的每一轴：

| 该轴一步是否 fits | L | H | 离开条件（向 +） |
|-------------------|---|---|------------------|
| 不卡边 | **L_open=0.5** | **H_open≈0.12** | free ≥ sticky + L + H |
| 卡边 | **L_edge=1.3** | **H_edge≈0.04** | free ≥ sticky + L + H |

- **纯右**：只判列轴，够则切一格。  
- **右下（斜向，方案 1）**：  
  - 列、行**都**过 L+H → **优先对角**；  
  - **仅列够** → 可先横移一格；**仅行够** → 可先竖移一格；  
  - 对角 !fits 时再尝试单轴（仍须 fits）。  
- 卡边 1.3 **不是**把影贴到障碍上，而是「该轴往死方向离开」用更大阈；目标仍须 fits。

### 4.4 施密特防闪（G-STABLE）

离开要 `L+H`，回到旧侧要过另一侧对称条件（相对**新** sticky 再判）。  
**禁止**用「换格后 N ms 时间锁」代替 H（会误伤横拖及时性）。

### 4.5 MAX_LAG

- 出厂 **1.45**，**必须 > L_edge(1.3)**。  
- 超过 → 灭影并清 sticky，不远距吸附。

### 4.6 firstPin

仅 sticky 空/非法：`round(free)` 为中心，±1 内 lag 最小且 fits。  
不做 1.3 卡边（尚无 sticky 可粘）。

## 5. 出厂参数（defaults 映射）

| 设计角色 | 常量 | 出厂 | 备注 |
|----------|------|------|------|
| L_open | `FEEL_GHOST_OPEN_SNAP` | **0.5** | 空地 |
| H_open | `FEEL_GHOST_SNAP_HYST` | **0.12** | 不闪优先 |
| H_open 下限 | `FEEL_GHOST_SNAP_HYST_MIN` | **0.1** | — |
| L_edge | `FEEL_GHOST_EDGE_HOLD` / `MIN` | **1.3** | 拍板 |
| MAX_LAG | `FEEL_GHOST_MAX_LAG` | **1.45** | > edge |
| 斜向扇区 | `FEEL_GHOST_DIAG_RATIO` | **0.45** | 进入对角 |
| 主轴 bias | `FEEL_AXIS_DOMINANCE` | **0.05** | 抑 E/SE 扇区抖 |

实际空地换格约在 **0.5+0.12 = 0.62 格**（相对 sticky 中心）。

## 6. 反查：历史坑 ↔ 方法是否闭合

| 现象 | 方法是否覆盖 | 实现注意 |
|------|----------------|----------|
| 影提前钉格 | ✅ L_open=0.5，不 0.28 | — |
| 格缝连闪 | ✅ H_open 足够 + 中心死区 + 失败保持 | 禁止时间锁 |
| 卡边太松 | ✅ L_edge=1.3 | 不被速度压低 |
| 斜拖先横后斜 | ✅ 对角一次切，假斜向走主轴 | 勿未达 ratio 就对角 |
| 斜拖本体过了影不跟 | ⚠️ 双轴都要 0.62；贴边斜绕堵轴 1.3 会粘 | 属 G-EDGE 与 G-DIR 取舍；假斜向已修 |
| 横拖偏钝 | ✅ 去掉 settle；H 固定不叠两次 | 勿再加大 H 无上限 |
| 甩影 | ✅ MAX_LAG 灭影 | 勿 nearest 全盘 |
| 多路径互殴 | ✅ 单流水线 | 代码已收敛 |

**已知取舍（不是漏实现）**  
贴着障碍**斜向**绕空地时：堵轴仍按 1.3 计 leave → 影会比纯空地斜移更粘。若产品要「斜绕更松」，应改设计为「只按**目标对角格**是否 fits 选 L，而非分轴 canStep」，而不是再打补丁。

## 7. 验收用例

| # | 操作 | 期望 |
|---|------|------|
| A1 | 空地慢速横拖过中线 | 约 0.62 格内投影换列；不闪 |

| A7 | 消行中再拖下一块 | 投影独立；不锁输入（game 层） |

## 9. 演进约定

1. 改投影 = 先改本文 §2–§5，再改 `ghost-policy`。  
2. 新现象先归 G-* 冲突，再改参数角色或 §4 流水线。  
3. **禁止恢复**：横移计入抬升、远距救命吸附、open≪0.5、失败乱吸、时间 settle 代替 H。  
4. 调 H_open 时：闪 → 略增；钝 → 略减，但 **≥ SNAP_HYST_MIN**，并跑 A1/A2。
